# 분자 구조로 피부 자극성 예측하기

덕성여자대학교 **AI머신러닝** (2026-1) 기말 개인 프로젝트입니다.
공개 데이터에서 학습 데이터셋을 만드는 것부터 최종 모델을 고르는 것까지 직접 진행했습니다.


---

## 무엇을 하는 프로젝트인가

화학물질의 **구조(SMILES)** 만 가지고 그 물질이 **피부에 자극을 주는지(1) 아닌지(0)** 를 맞히는 모델을 만듭니다.

동물실험이나 사람 대상 시험을 거치지 않고도 위험한 물질을 미리 걸러내자는 것이 목적입니다.

## 1. 데이터 — 신뢰도 높은 것부터 쌓아 올리기

처음부터 데이터를 다 합치지 않고, **믿을 수 있는 순서대로 한 단계씩 더하면서** 그때마다 무엇이 좋아지고 무엇이 나빠지는지 확인했습니다.

| 단계 | 추가한 것 | 건수 |
|---|---|---|
| 1 | 사람 In Vivo 단독 | 81 |
| 2 | + 토끼 In Vivo | 138 |
| 3 | + In Vitro | 181 |
| 4 | + 피부 감작(sensitization) | **266** |

최종 266건의 라벨 비율은 자극 156 / 비자극 110 입니다.

**왜 이 순서였나** — 사람 대상 데이터가 가장 신뢰도가 높지만 81건은 모델을 학습시키기엔 너무 적습니다. 그래서 신뢰도를 한 칸씩 양보하는 대신 데이터 양을 얻는 교환을 단계마다 눈으로 확인하며 진행했습니다.

**정제 과정에서 한 일**

- 같은 물질에 서로 다른 라벨이 붙은 경우를 단계별로 제거 (16건 / 62건 / 142건)
- RDKit으로 염(salt)을 떼어내고 SMILES 표준화 → 같은 물질이 다른 표기로 중복되는 것 방지

**feature** — RDKit 2D descriptor 217개 + Morgan fingerprint 등 4,263개 = **4,485개 열**
→ 값이 거의 변하지 않는 열을 걷어내고 **3,437개**로 축소

## 2. 모델 — 6종을 같은 조건에서 비교

LogisticRegression · MLP · SVM · DecisionTree · RandomForest · XGBoost

- feature 개수 `k` 를 20 / 40 / 80 / 160 / 240 / 320 으로 바꿔가며 전부 시도
- 5-fold 교차검증
- 지표 6종: 정확도 · 균형정확도 · F1 · MCC · 민감도 · 특이도

### 최종 선택: MLP (k=320)

| 지표 | 값 |
|---|---|
| 정확도 | 0.797 |
| 균형정확도 | 0.791 |
| F1 | 0.829 |
| MCC | 0.584 |
| 민감도 | 0.827 |
| 특이도 | 0.755 |

전체 실험 기록은 [`results/experiment_results.csv`](results/experiment_results.csv) 에 있습니다.

## 직접 정해야 했던 것들

코드는 AI 도구의 도움을 받아 작성했지만, **아래는 넘길 수 없는 판단이었습니다.**

**① 어떤 데이터를 어디까지 합칠지**
신뢰도와 데이터 양은 맞바꿈 관계입니다. 어디서 멈출지는 정답이 없어서, 단계마다 결과를 보고 정했습니다.

**② 무엇을 기준으로 모델을 고를지**
정확도만 보면 안 되는 데이터입니다. 자극(156) 과 비자극(110) 이 한쪽으로 치우쳐 있어서, 많은 쪽만 맞혀도 정확도는 높게 나옵니다.
그래서 **균형정확도 · F1 · MCC 세 지표의 평균**을 최종 기준으로 삼았습니다. 한 지표가 운 좋게 높은 모델이 뽑히지 않도록 하기 위해서입니다.

**③ 나온 숫자를 믿어도 되는지**
최종 모델의 **학습 정확도가 1.000** 입니다. 보통은 좋은 신호가 아니라 외워버렸다는 신호입니다.
feature가 3,437개인데 데이터는 266건이니 과적합이 생기기 쉬운 구조입니다. 이 점을 결과에 숨기지 않고 노트북에 적어두었습니다.
